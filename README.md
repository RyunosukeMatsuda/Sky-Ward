# SKYWARD — 3D Air Combat Prototype 06

`index.html` を最新のPC/スマホのブラウザで開くだけで動きます（ビルド不要）。
Three.js 0.160.0 を CDN（cdn.jsdelivr.net）から読み込むため、初回起動時はインターネット接続が必要です。

## 操作（PC）

| キー | 操作 |
|---|---|
| W / S | ピッチ（機首上げ / 下げ）※設定で反転可 |
| A / D | ロール（地上では前輪ステアリング） |
| Q / E（← / →） | ヨー（ラダー） |
| Shift / ↑ | 推力レバーを上げる（MIL 82%で一旦止まる。押し直すとアフターバーナー） |
| Z / ↓ | 推力レバーを下げる |
| マウスホイール / 数字キー1〜9・0 | 推力レバーを直接設定（0 = 100%） |
| 画面右下のレバー | ドラッグで推力設定 |
| G | 着陸装置（ギア） |
| B | ホイールブレーキ（推力0%でも自動でかかる） |
| Space | 機関砲 |
| F / Enter | ミサイル発射 |
| C | 小型 / 大型ミサイル切替 |
| T / Tab | 目標切替 |
| X | フレア |
| V | 追跡視点 / コックピット視点 |
| M | サウンド ON / OFF |
| Esc | 一時停止（結果画面では拠点へ戻る） |

## 操縦設定

ホームの「操縦設定」または一時停止メニューから、ピッチ感度・ロール感度（30〜130%、初期値70%）、入力のなめらかさ、スティック中央の効き（タッチ・傾き操作）、ピッチ反転を変更できる。設定はブラウザに保存される。

## スマホ（横画面専用）

- 縦向きのときは「横向きにしてください」と表示され、一時停止する。
- **左半分**：指を置いた場所がスティックの中心になる（フローティングスティック）。上下でピッチ、左右でロール。
- **左端のレバー**：推力。
- **右下**：GUN（押している間射撃）、MSL（ロック中は枠が光る）、目標・武装・フレア・ギア。地上ではフレアがブレーキに変わる。着陸が近いのにギアが上がっているとギアボタンが点滅する。
- **中央下の表示**：地上で「推力をMILにして射出」「離陸推力」をタップで実行。
- **かんたん操縦**（スマホの初期値）：スティックを倒した方向へ機体が傾いて自動で旋回し、指を離すと水平に戻る。離陸後はギアも自動で格納。設定でマニュアルに切り替えられる。
- 設定画面から 画質・サウンド・傾き操作・全画面 も切り替えられる。

## 離陸と着陸

- ホームの「出撃拠点」で 空母（カタパルト）／陸上基地（滑走路）／空中から を選べる。
- 空母：推力レバーを80%以上にして1.2秒保つとカタパルト射出。甲板の端を越えると発艦。
- 基地：推力を上げて加速し、離陸速度（VR）を超えたら W で機首上げ。
- 着陸：G でギアを下ろすと、緑のリング（3.5°のグライドパス）、接地点、降下率、推奨進入速度が表示される。
  - 接地条件：ギアが出ている、降下率が基地6.5m/s・空母8.5m/s以下、傾きが小さい、機首が下がっていない。
  - 空母は甲板の後半部に接地するとアレスティングワイヤーが掛かって停止する。前半部だとボルター（推力を上げて再離陸）。
- 任務目標を達成したら、空母か基地に着陸して停止すると帰投完了（ランクに加点）。一時停止メニューの「ここで任務終了」で省略もできる。

## オンライン（2〜4人）

遊ぶ場所は2通り。

- **claude.ai 上（おすすめ）**：アーティファクトをそのまま開く。更新は公開と同時に反映される。参加者は claude.ai にログインしている必要があり、持ち主が共有メニューから招待する（攻撃を送るにはコントリビューター以上の権限が必要。閲覧のみの人は飛べるが攻撃は届かない）。オンライン画面に「参加できる部屋」が一覧で出るので、タップで入れる。誰が抜けても部屋は続く。
- **Netlify などに置いた単体版**：`index.html` をブラウザで直接開く。下の手順どおり、部屋コードか招待リンクで参加。

1. ホームの「オンライン（2〜4人）」を開き、コールサインを入力。
2. ホスト：モード（対戦／一緒に飛ぶ）を選んで「部屋を作る」。6文字の部屋コードが出るので、コードか「招待リンクをコピー」で友達に送る。
3. 参加者：コードを入力して「入る」（招待リンクから開くとコードは自動で入る）。
4. 全員「出撃」。途中参加もできる。

- **対戦（ドッグファイト）**：空中から出撃。先に5機撃墜で勝利、スコアは自動でリセットされ次のラウンドへ。撃墜されると約5秒後に再出撃（3秒間無敵）。左上に撃墜数／被撃墜数。
- **一緒に飛ぶ**：武器なし。ホームで選んだ出撃拠点（空母・基地・空中）から全員で出撃。仲間は緑で表示。
- 通信はプレイヤー同士の直接接続（WebRTC）。最初の接続仲介に PeerJS の無料公開サーバー（0.peerjs.com）を使う。自前のサーバーは不要。
- 単体版ではホストが部屋を出ると部屋は閉じる。
- 内部エラーが起きてもゲームは止まらず、画面に「内部エラー（ゲームは続行）」と表示される。表示された文を開発側に伝えると原因調査に使える。
- 会社・学校のネットワークや一部のモバイル回線では直接接続できないことがある。その場合は PeerJS の中継サーバー経由になり、遅延が増えることがある。
- 当たり判定：機関砲は撃った側、ミサイルは撃たれた側の画面で判定する。

## デプロイ（Netlify）

フォルダ `SKYWARD` をそのまま Netlify にドラッグ＆ドロップするか、既存サイトの `index.html` を差し替える。ビルド設定は不要。HTTPS で配信されていれば動く。

## 収録内容

- 3D空域、コードで組んだ5機種（ギアつき）、敵機・艦艇・空母（周回航行）、陸上基地
- 6自由度の操縦、失速、G制限、ギアの抗力
- 低空飛行時の水しぶき（高度約34m以下、速度と高度で強さが変わる）
- 戦闘、HUD、レーダー、効果音、任務結果とランク
