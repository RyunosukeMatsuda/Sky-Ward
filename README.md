# SKYWARD — プロトタイプ13

ブラウザで遊ぶ3D空戦ゲーム。`index.html` 1枚で動く（Three.js と通信ライブラリはCDNから読み込む）。

## 公開

https://skyward8.netlify.app/ で公開している。このリポジトリの `main` に更新を送ると、Netlify が1〜2分で自動公開する（ビルド不要、設定は `netlify.toml`）。

## 機体（13機）

F-15、F-22、F-117、B-2、F-35、F-14（可変翼）、MiG-23（可変翼）、XF-X 次世代機、HX-1（オリジナル極超音速機）、TB2（無人機）、FX-7 Petrel（オリジナルの可変翼＋カナード艦上戦闘機）、F2Y Sea Dart（水上ジェット戦闘機）、SF-9 Tiderunner（オリジナルの飛行艇戦闘機）。

F2YとSF-9は海のどこにでも着水・離水できる。着水したら推力を絞って減速、推力を上げて機首を起こせば離水。

FX-7だけ、ホーム画面の「追加装備」で背中のブースター・ポッド・装甲板・専用塗装を付け外しできる（見た目だけ、性能は同じ）。

## ミサイル（出撃前に2種類を選択）

航空自衛隊の9種類：AIM-7F/M、AIM-9E、AIM-9L/M、AIM-9P、AAM-3（90式）、AAM-4（99式）、AAM-5（04式）、ASM-1（80式）、ASM-2（93式）。ホーム画面で枠1・枠2に1つずつ入れ、飛行中に C キー（スマホは「切替」）で切り替える。性能はゲーム用の値。

## 操作（PC）

- W/S ピッチ、A/D ロール、Q/E ヨー
- Shift・↑ / Z・↓ 推力レバー（82%より上はアフターバーナー）
- Space 機関砲、F ミサイル、C ミサイル切替、T 目標切替、X フレア
- G ギア、B ブレーキ、R 後方カメラ、V 視点切替、M 音のオン・オフ

弾薬（機関砲・ミサイル・フレア）はすべて無制限。

## オンライン（2〜4人）

ホームの「オンライン」→ コールサインを入力 → モードを選んで「部屋を作る」。部屋コードか招待リンクを友達に送り、受け取った人はコードを入力して「入る」。

- **対戦**：全員が敵。先に5機撃墜した人の勝ち。
- **チーム戦**：ALPHA（青）とBRAVO（赤）に分かれる（2対2まで）。入ると人数の少ないチームに自動で入り、ロビーのボタンで移動もできる。チームの撃墜数の合計が先に7機に届いたほうが勝ち。味方には弾が当たらずロックもしない。味方はHUDとレーダーで緑。
- **一緒に飛ぶ**：武器なし。

撃墜されると約5秒後に再出撃（3秒間は無敵）。通信は公開のMQTT中継サーバー（EMQX / HiveMQ）を経由するので、自前のサーバーは要らない。全員が同じ版を開いている必要がある（古い版の人はチーム戦を「対戦」として扱ってしまう）。
